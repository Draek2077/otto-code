== Diagrams

The whole point: a `[mermaid]` block renders through the same `MermaidBlock`
that a fenced diagram in a `.md` file uses, so both look identical.

== Source blocks

[source,typescript]
----
export function asciiDocToMarkdown(source: string): AsciiDocDocument {
  const lines = source.replace(/\r\n?/g, "\n").split("\n"); // <1>
  const header = parseDocumentHeader(lines); // <2>
  return { frontmatter: formatFrontmatter(header.entries), body: "" };
}
----
<1> Newlines are normalized first.
<2> The header is parsed before the body.
