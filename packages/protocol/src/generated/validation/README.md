# Generated protocol validators

`ws-outbound.aot.ts`, `ws-outbound-metadata.aot.ts`, and `ws-outbound-dispatch.aot.ts` are generated by `packages/protocol/scripts/generate-validation-aot.mjs` from `packages/protocol/codegen/ws-outbound.compile.ts`.

Run:

```bash
npm run generate:validators --workspace=@otto-code/protocol
```

The generated TypeScript is intentionally gitignored. zod-aot is exact-pinned because this is a young solo-maintainer project; keep the generated validators behind protocol regression tests when upgrading it.
