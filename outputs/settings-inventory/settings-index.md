# Otto Settings Inventory

> Snapshot: 2026-08-24. Generated from the current working tree, including visible uncommitted changes. This indexes controls rendered inside Settings, including preferences, credentials, actions, conditional information rows, nested editors, dynamic row patterns, keyboard commands, and finite catalog choices. Navigation-only controls such as Back, Switch host, and search/filter affordances are excluded.

## Summary

- **Total indexed entries:** 405
- **App surface:** 174
- **Host surface:** 231
- **Persistence scopes:** App, Desktop, Host, and Project. Surface and persistence scope are intentionally separate because some Host pages contain device-local settings.
- **Dynamic entries:** A single row documents an unbounded runtime collection, such as one row per installed language server or team member. Finite catalogs and keyboard commands are enumerated individually.

## Method and interpretation notes

1. The Settings route map was traced from the Settings shell into every App and Host page.
2. Nested sheets and editors were followed separately, including personalities, teams, providers, connectors, terminal profiles, and project settings.
3. English labels and descriptions were reconciled against rendered controls and persistence paths.
4. All rebindable keyboard commands and all current finite connector-catalog entries were enumerated.
5. Conditional controls are included with their visibility requirement. Runtime-created collections are represented by a documented dynamic pattern instead of inventing a fixed list.
6. Brain model-library controls used by the operational Brain tabs are excluded because they are not rendered in Settings. Settings navigation, search, Back, Switch host, and transient filter controls are likewise excluded.
7. Source paths and line numbers were validated against the snapshot used to generate this document.
