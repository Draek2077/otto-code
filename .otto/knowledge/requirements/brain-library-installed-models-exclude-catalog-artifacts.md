# Brain Library installed models exclude catalog artifacts

<!-- compiled_truth -->

In Brain Library, the Installed models section lists only Hugging Face-discovered artifacts that are not represented by any curated catalog entry. A catalog entry's primary artifact and every declared bundled option are excluded from this section.
