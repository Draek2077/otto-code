# Brain Benchmark run action lives in Runs header

<!-- compiled_truth -->

The Brain Benchmark “Run the suite” action is placed in the right side of the Runs section header directly above the Runs table, rather than in the top benchmark list toolbar. The placement applies across desktop and compact layouts while the run-count summary remains in the top toolbar.
