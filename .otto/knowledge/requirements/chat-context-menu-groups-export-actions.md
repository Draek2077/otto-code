# Chat context menu groups export actions

<!-- compiled_truth -->

The chat context menu exposes a single `Export >` entry before a separator, followed by `Expand all` and `Collapse all`. Choosing Export opens the JSON, HTML, Markdown, and Text options together, without a separator between JSON and the other formats.
