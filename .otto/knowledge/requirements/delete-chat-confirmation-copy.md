# Delete chat confirmation uses compact three-sentence copy

<!-- compiled_truth -->

The Delete chat confirmation uses three concise sentences: permanently delete Otto's record, row, and metadata; state that the provider transcript remains on the host and can still be read or resumed; and state that the change cannot be undone. The record sentence must not claim the title is separately deleted.
