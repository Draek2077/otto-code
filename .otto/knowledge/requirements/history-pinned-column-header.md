# History has a pinned filter and column header

<!-- compiled_truth -->

The History page must present its filter controls and descriptive column labels in a bordered header region above the history list. The header remains pinned while the history rows scroll, and the labels align with the Conversation, Project, Host, Branch, and Last active columns on desktop.
