# File drops outside the Composer open the Text Editor

<!-- compiled_truth -->

Dropping a file over a chat Composer remains an attachment action with Copy feedback. Dropping a file anywhere else in the Otto UI must show feedback that it will open the file in the Text Editor and must open it through the same file-open path used when a file is opened from the OS shell.
