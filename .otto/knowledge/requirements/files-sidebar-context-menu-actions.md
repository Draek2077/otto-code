# Files sidebar context menu actions

<!-- compiled_truth -->

The Files-sidebar file context menu keeps Edit and Git history in the bottom action section, and does not show New file or New folder. Neither the Files-sidebar right-click menu nor the row's `…` menu shows a Size metadata row for folders, because folders do not have file sizes.
