# Brain model name actions are compact and icon-only

<!-- compiled_truth -->

In Brain’s Models settings detail pane, Rename and Reset name sit immediately beside the model name on the first header row. Rename, Reset name, and Delete render as icon-only controls with accessible labels and tooltips; their visible text labels are not shown.
