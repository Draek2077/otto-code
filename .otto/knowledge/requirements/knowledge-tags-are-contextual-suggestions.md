# Knowledge tags are contextual suggestions

<!-- compiled_truth -->

Knowledge entry tags remain free-form and user-authored. The UI may suggest general-purpose tags appropriate to the entry type and reuse existing repository tags, but it must not prefill, require, or restrict tag choices. Entry type and review status are metadata, not tags.
