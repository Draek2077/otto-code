# Material symbol icons are generated from the source map

<!-- compiled_truth -->

`packages/app/src/assets/material-symbol-icons.ts` is generated by `packages/app/scripts/generate-material-symbols.mjs` from `packages/app/scripts/material-symbols-map.json` and must never be hand-edited: adding an icon export to `material-icons.ts` without a matching map entry produces a silent blank render (`SvgXml` with `xml={undefined}` draws an empty box), and the next regeneration wipes any hand-pasted entries. Add the name→symbol mapping to the map, rerun the generator, then format the asset with oxfmt. A regression test at `packages/app/src/components/icons/material-icons.test.ts` now fails the build when any exported icon resolves to a missing or empty SVG.
