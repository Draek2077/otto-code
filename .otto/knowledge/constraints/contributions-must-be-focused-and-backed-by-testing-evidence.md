# Contributions must be focused and backed by testing evidence

<!-- compiled_truth -->

Changes should remain focused, link to an issue, explain the problem and reproduction when relevant, include QA/testing evidence, and disclose platform coverage. Basic formatting, lint, and typecheck failures are acceptance blockers; UI changes require captures for every affected platform.
