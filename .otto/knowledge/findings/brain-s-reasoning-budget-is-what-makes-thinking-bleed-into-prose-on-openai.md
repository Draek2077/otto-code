# Brain's reasoning budget is what makes thinking bleed into prose on OpenAI-compat chats

<!-- compiled_truth -->

The "thinking breaks out of thinking" bleed on OpenAI-compatible providers originates in Otto Brain, not in the stream parser. `args.ts` passes `--reasoning-budget N --reasoning-budget-message "Enough analysis. Write the complete answer now."` to llama-server. On reaching N reasoning tokens the engine appends that message and closes the thought wherever the model happens to be - always mid-sentence. The model was not finished, so its continuation lands on the `content` channel and renders as prose (thinking bleeds out and never returns); if it re-opens a think block, a second thought block appears back to back. The frequency tracks the budget: Qwen3.8-27B was capped at 512 and hit it on 17% of thinking rounds (22 of 128 in one session), while every model at 1536 (gemma-4-31B, Muse-Glimmer-30B) hit it 0 times across 25 rounds. The tight caps come from `ops/sweep.ts`, whose ranking is structurally biased toward small budgets: it scores one pure-output task (write four complete Python files, no elisions) by files delivered, tie-broken by content-per-second. Reasoning produces no content and costs time, so the smallest budget that still delivers all four files always wins - which is why swept models sit at 0 (Ornith APEX), 512 (Qwen3.8-27B) and 1024 (Ornith NVFP4) while unswept ones sit at the 1536 default. The sweep's documented purpose is finding the cap past which a model degenerates into reasoning forever; what it actually measures is typing speed on a task that needs no reasoning. Separately, reasoning preservation is never enabled for these models: Otto only implements the template-kwarg path, detecting the literal strings `preserve_thinking`/`preserve_reasoning` in the chat template (`gguf.ts` detectTemplateReasoningCapabilities) and emitting `--chat-template-kwargs`. Qwen3.8-27B's template gates thinking with `enable_thinking`, so no `templateArgument` is detected, no kwarg is emitted, and the profile toggle never appears - while llama-server itself logs "chat template supports preserving reasoning, consider enabling it via --reasoning-preserve", a server flag Otto never passes.
