# The 0.8.10-to-HEAD release cycle had no green CI baseline; Playwright successes were path-filtered skips

<!-- compiled_truth -->

Across the last 20 CI runs on `main` (2026-08-14 through 2026-08-18), every run in which the Playwright E2E suite actually executed failed, and every run reporting `success` had skipped Playwright entirely via a path filter. The E2E suite therefore has no green baseline anywhere in the 0.8.10-to-HEAD window, and the reported instability of this release is not attributable to any single commit: the work was developed for five-plus days with no functioning test gate. Tag `v0.8.10` was itself cut on a CI run that ended `cancelled`, so 0.8.10 shipped without CI passing either.

The enabling defect is that the path-filtered skip reports job `success` rather than `skipped` or `neutral`. A commit touching only filtered-out paths (for example a Brain-only or docs-only change) makes all eight Playwright shards report green while running zero tests, so a continuously red suite is indistinguishable from a healthy one at a glance in the run list.
