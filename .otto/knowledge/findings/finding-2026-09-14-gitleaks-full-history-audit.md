# Gitleaks full-history audit: no real credential has ever been committed to otto-code

<!-- compiled_truth -->

A redacted gitleaks 8.30.1 scan of every reachable commit (all local refs, merge diffs, and the 60 GitHub pull refs) plus the non-ignored working tree found 14 unique hits, all triaged as non-credentials, and zero real leaks. None of the must-never-commit credentials (HubSpot/Box client secrets, Cloudflare API token, Google Desktop OAuth JSON, Android release keystore or passwords, Expo, npm, GitHub, Anthropic, OpenAI, OpenRouter tokens, non-fixture private keys) appear anywhere in history. A proposed .gitleaks.toml with rule-and-file-scoped allowlists brings all four scopes to zero findings; it is not committed. Binary blobs and GitHub-side unreferenced objects are outside what this method can see.
