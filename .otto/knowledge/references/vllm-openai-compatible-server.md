# vLLM OpenAI-Compatible Server

<!-- compiled_truth -->

vLLM documents an OpenAI-compatible HTTP server launched with `vllm serve`, including chat-completions support. Otto will use this as evidence that the common Brain host can retain an OpenAI-compatible serving boundary while a vLLM driver owns runtime-specific installation, lifecycle, artifacts, telemetry, and tuning.
